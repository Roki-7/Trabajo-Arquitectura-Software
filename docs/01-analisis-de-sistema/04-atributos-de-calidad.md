# Atributos de calidad

Los atributos de calidad indican cómo debe funcionar la plataforma, además de las funciones que ofrece.

En este proyecto se consideran la rapidez de respuesta, la disponibilidad, la capacidad de crecimiento, la seguridad, la facilidad de mantenimiento y uso, la adaptación a distintos dispositivos y la conservación correcta de la información.

| ID | Atributo de calidad | Escenario de calidad |
|---|---|---|
| AC01 | **Rendimiento** | Cuando varios usuarios buscan servicios, consultan perfiles o comparan cotizaciones al mismo tiempo, la plataforma debe responder sin demoras que dificulten completar estas tareas. |
| AC02 | **Disponibilidad** | Los clientes y prestadores deben poder acceder a las funciones principales de búsqueda, solicitudes, cotizaciones y contrataciones durante los periodos de servicio establecidos. |
| AC03 | **Escalabilidad** | Cuando aumente la cantidad de usuarios, servicios, solicitudes y contrataciones, la plataforma debe permitir ampliar sus recursos para atender la demanda sin requerir un rediseño completo. |
| AC04 | **Seguridad** | Cuando un usuario intenta consultar o modificar información, la plataforma debe comprobar sus permisos y proteger las cuentas, datos personales y documentos frente a accesos no autorizados. |
| AC05 | **Mantenibilidad** | Cuando se corrige un error o se incorpora una función, como el futuro cobro por servicios de la plataforma, el cambio debe concentrarse en las partes relacionadas y conservar el funcionamiento de las demás. |
| AC06 | **Usabilidad** | Los clientes y prestadores deben poder comprender y completar las tareas principales mediante instrucciones claras y pasos adecuados al trabajo, sin exigir a una reparación pequeña el mismo proceso que a una obra completa. |
| AC07 | **Adaptabilidad** | Cuando se utiliza la plataforma desde celulares, tabletas, computadoras o laptops, la interfaz debe ajustarse al tamaño de pantalla y permitir completar las tareas principales en los navegadores definidos para el proyecto. |
| AC08 | **Resiliencia** | Si falla temporalmente la IA, las notificaciones o los mapas, la plataforma debe informar lo ocurrido y mantener disponibles las funciones independientes. Cuando el servicio se recupere, debe permitir reintentar las operaciones afectadas sin duplicar sus registros. |
| AC09 | **Integridad de la información** | Ante acciones simultáneas, solicitudes repetidas o fallas durante el guardado, la plataforma debe evitar contrataciones duplicadas y registros incompletos, impedir cambios que no hayan sido aceptados y conservar las versiones anteriores de los acuerdos. |
